# 电压调控下液晶威廉姆斯畴衍射的研究

## 写在前面

这原本只是（当然，现在大概也只是）一个ZJU化学系大二本科生的《普通物理学实验II》课程中的一个小课题。

首先我承认，这整个项目的代码构建，确实是由ChatGPT老师完成的，本人没有手敲过一行源码。这个项目作为vibe coding的产物，显然也有不少槽点、可以批评之处。

然而，没有我本人不断的调整和指导，并在做中学、学后再反过来指导着做，如今的小成果，如今的这个项目，想必也不会存在。

最初接到这个课题时，在GPT的帮助下，我开始文献调研和理论知识的学习，再接着是实验设计、组织小组成员进行实验，处理数据，分析，写论文。

中间真是经历了很多很多的小坎坷，纵使它们在真正的科学研究场景所遇到的各种困难面前，根本不值一提。但一步步解决问题的过程中，很多收获真的是超乎我意料的——

- 相机对着光屏拍，好难好难正对光屏，怎么办？
  
  那就先测量光屏尺寸，识别光屏四角，利用透视关系和坐标变换，把斜着拍歪的光屏还原成正视图。

- 怎样对衍射光斑进行识别和标记？
  
  那就用亮度积分，设置筛选阈值。

- 怎么排除反射导致的杂光斑？如果排除它需要提高阈值，又怎么保证弱的衍射光斑被保留？
  
  那就先拉高阈值识别出一些准确的光斑，拟合出规则的点阵作为预测，然后在预测点附近，结合形态的筛选条件，精确地找到光斑。（也正是在这个拟合过程中，我发现了一维二维光斑的周期不同）

- Raw照片几乎大部分的中心光斑都过曝了，那我怎么描述亮度？
  
  于是转念一想，红色光斑过曝了，那绿色通道呢？取数据一处理，发现 G与R通道亮度有很好的线性关系，于是用绿色通道来拟合。

......像这样的例子还有很多很多。

我承认，当今的AI Agent力大砖飞，但以上这些解决问题的idea，确确实实是我自己想出的。没有我的引导，Codex自己并不知道可以这样做；但没有Codex，我这样的idea则又完全没有落地的可能——实际上，以上所列举的这些问题的发现和解决，是从我下午拿到第一批拍摄的raw文件，到晚上完成第一批图像处理的过程中发生的。

这短短几个小时所搭建的程序，如果放在代码纯手搓的时代，没有一两个月大概是做不出来的。

于是我就想到了在校园论坛看到的一段话：“以前，技术的价值占比远大于你的偏好，所以你没有动机去完成这个开发；现在你的偏好已经变成了真正的价值，而开发的价值微不足道，所以你通过vibe coding放大了你的偏好。换句话说，如果你从价值的演变中思考这个问题就会发现，AI并不应该说是夺走了你的价值，而应该说它在一步步把属于人的部分还给你，因此它反而突出了人的真实价值。“

“AI并不应该说是夺走了你的价值，而应该说它在一步步把属于人的部分还给你，因此它反而突出了人的真实价值。”

我想，这或许可以稍稍回应一些AI时代的存在主义焦虑、价值焦虑。

本项目配套了我的论文（真的是拙作），试图基于”电压调控的液晶威廉姆斯畴衍射“这一小课题，建立从图像测量到解释其原理的过程。

借此项目，可以查看论文中所述算法的源码，并进行运算。

## 开始使用

完整解压便携包，在项目文件夹内双击：

| 系统      | 入口                         |
| ------- | -------------------------- |
| macOS   | `run_reproduction.command` |
| Windows | `run_reproduction.bat`     |

首次双击启动器需要联网，自动从官方源准备项目内环境（大概要一分钟左右）；完成后可离线运行。

只想阅读时，直接打开 `START_HERE.html`。

便携环境面向 Windows 10/11 x64 和 macOS 14+（Apple Silicon / Intel）。

## 研究路线

**建立测量工具 → 观察图样演化 → 测量周期 → 解释光强分配 → 联系微观结构。**

案例包含坐标变换、强弱光斑识别与预测补检、RG 拟合、CFA 测光、二维傅里叶频谱与谐波判断，以及一维双谐波和二维双斜向模型。

## 源码与结果

启动入口为 `scripts/start.py`，核心算法在 `src/williams_diffraction/`。网页“源码导览”按研究问题连接到具体函数。

输入在 `data/`，随包结果在 `results/`，每次新计算单独保存在 `work/lab_runs/`。运行案例不需要完整 RAW 或原视频。
